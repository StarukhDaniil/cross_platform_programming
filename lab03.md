# Лабораторна робота 3. Імпорт каталогу бібліотеки

Старух Даніїл, ФЕІ-35

У `BookDto(string Id, string Isbn, string Title, int Year)` усі поля обов’язкові. Id ідентифікує запис, Isbn зберігає код видання як текст, Title містить назву, а Year — додатний цілий рік видання. Для книги обрано record, бо він зберігає значення одного рядка та автоматично порівнює записи за їхніми полями.

`ImportResult<T>(IReadOnlyList<T> Items, IReadOnlyList<string> Errors)` повертає обидві колекції. Коли записів або помилок немає, відповідна колекція порожня, тому nullable-поля тут зайві.

## Формат і розбір

Файл UTF-8 має чотири поля з роздільником `;`. Заголовок `id;isbn;title;year` необов’язковий. Порожні рядки й коментарі з `#` пропускаються, але враховуються в нумерації.


```csharp
return fields switch
        {
            { Length: not 4 } => new Failed($"очікується 4 колонки, отримано {fields.Length}"),
            ["", _, _, _] => new Failed("порожній ідентифікатор"),
            [_, "", _, _] => new Failed("порожній ISBN"),
            [_, _, "", _] => new Failed("порожня назва книги"),
            [var id, var isbn, var title, var year]
                when int.TryParse(year, NumberStyles.None, CultureInfo.InvariantCulture, out int value)
                    && value > 0 => new Parsed(new BookDto(id, isbn, title, value)),
            _ => new Failed($"рік «{fields[3]}» має бути додатним цілим числом")
        };
```

Патерн властивості Length із not виявляє неправильну кількість колонок. Патерни списку знаходять порожні обов’язкові поля, var зв’язує значення, а when перевіряє рік із InvariantCulture. Гілка _ повідомляє про некоректний рік.
